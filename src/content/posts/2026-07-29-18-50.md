# 64.最小路径和

[题目链接](https://leetcode.cn/problems/minimum-path-sum/?envType=study-plan-v2&envId=dynamic-programming)

[上一篇](https://note.synitis-awa759.xyz/posts/2026-07-25-22-58/)

这一篇和上一篇完全一样，只是从路径数变成了花费，直接写代码就行

```cpp
class Solution {
public:
    int minPathSum(vector<vector<int>>& grid) {
        if(size(grid) == 1){
            int add = 0;
            for(auto i : grid[0]) add += i;
            return add;
        }
		//特殊处理
        for(int i = 1;i<size(grid);i++){
            grid[i][0] += grid[i-1][0]; 
        }
        for(int i = 1;i<size(grid[0]);i++){
            grid[0][i] += grid[0][i-1]; 
        }
		//对gird的第1行、列进行初始化
        for(int i = 1;i < size(grid);i++){
            for(int j = 1;j < size(grid[0]);j++){
                grid[i][j] += min(grid[i-1][j],grid[i][j-1]);
				//每格最小花费 += min(上一格最小花费，左一格最小花费)
            }
        }
        return grid[size(grid) - 1][size(grid[0]) - 1];
    }
};
```
